## How to run

1. Start a Ganache QUICKSTART workspace at `http://127.0.0.1:7545`.
2. Open each file in Remix and compile with Solidity 0.8.x.
3. In **Deploy & Run**, select **Custom - External Http Provider** and connect to Ganache.
4. Deploy, execute the test cases in `report/REPORT.md`, then save the evidence in `screenshots/`.
